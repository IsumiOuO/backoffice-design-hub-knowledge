## 狀態定義

- `not-started`：尚未建立規格
- `ai-draft`：AI 草稿已建立
- `needs-review`：等待人工確認
- `queryable`：已可供查詢
- `product-confirmed`：產品規則已確認
- `dev-qa-ready`：開發與 QA 規格完整

## 使用方式

1. 人員閱讀本檔掌握進度。
2. 更新狀態時修改 `specs/spec-status.json`。
3. 執行 `npm run knowledge:tracker` 重新產生本表。
4. Telegram Bot 可用 `/progress`、`/todo`、`/waiting`、`/next`、`/module 資料庫管理` 查詢。
